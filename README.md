# WhateverClock

WhateverClock is an iOS application focused on displaying both analog and digital clocks of the current time. Developed with mechanical watch enthusiasts and precision seekers in mind, WhateverClock helps you accurately set your watches or reference the precise current time with ease.

## Purpose

The main goal of WhateverClock is to provide a clear, accurate, and visually appealing display of both analog and digital clocks. Whether you want to synchronize your mechanical watch or simply appreciate a beautiful time display, WhateverClock is the ideal tool.

## Features

- **Accurate Analog Clock:** Real-time, smoothly animated analog clock face to mimic mechanical watches.
- **Clear Digital Display:** Large, easy-to-read digital clock supporting 12/24 hour formats.
- **Home Screen Widgets:** Add beautiful analog, digital, or combined clock widgets to your home screen.
- **Customizable Appearance:** Personalize colors for clock face, hands, numbers, and digital display.
- **Battery Efficiency:** Optimized for long usage without draining your device.
- **Localization Ready:** Prepared for multiple languages (contributions welcome!).

## Usage

1. Launch the app to see both analog and digital clocks in sync.
2. Use the clear precise display to set your mechanical watches accurately.
3. Customize the appearance via settings as you prefer.
4. Add the widget to your home screen for a quick time reference.

## Getting Started

### Prerequisites

- Xcode 16.0+
- iOS 16.6+
- Swift 5.7+

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/marchein/WhateverClock.git
   ```

2. Open `WhateverClock.xcodeproj` in Xcode.
3. Select your simulator or device, then build and run.
